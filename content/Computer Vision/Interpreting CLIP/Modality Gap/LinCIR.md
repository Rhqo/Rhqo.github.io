# Language-only Efficient Training of Zero-shot Composed Image Retrieval

> [!Abstract] Abstract
> Composed image retrieval (CIR) task takes a composed query of image and text, aiming to search relative images for both conditions. Conventional CIR approaches need a training dataset composed of triplets of query image, query text, and target image, which is very expensive to collect. Several recent works have worked on the zero-shot (ZS) CIR paradigm to tackle the issue without using pre-collected triplets. However, the existing ZS-CIR methods show limited backbone scalability and generalizability due to the lack of diversity of the input texts during training. We propose a novel CIR framework, only using language for its training. Our LinCIR (Language-only training for CIR) can be trained only with text datasets by a novel self-supervision named self-masking projection (SMP). We project the text latent embedding to the token embedding space and construct a new text by replacing the keyword tokens of the original text. Then, we let the new and original texts have the same latent embedding vector. With this simple strategy, LinCIR is surprisingly efficient and highly effective; LinCIR with CLIP ViT-G backbone is trained in 48 minutes and shows the best ZS-CIR performances on four different CIR benchmarks, CIRCO, GeneCIS, FashionIQ, and CIRR, even outperforming supervised method on FashionIQ.
> 
> Composed image retrieval(CIR) 작업은 이미지와 텍스트의 합성 쿼리를 사용하여 두 조건 모두에 대한 상대 이미지를 검색하는 것을 목표로 합니다. 기존의 CIR 접근 방식은 쿼리 이미지, 쿼리 텍스트, 타겟 이미지의 triplet으로 구성된 학습 데이터셋을 필요로 하며, 이는 수집 비용이 매우 많이 듭니다. 최근 여러 연구들은 사전에 수집된 삼중항을 사용하지 않고 이 문제를 해결하기 위해 제로샷(ZS) CIR 패러다임을 개발했습니다. 그러나 기존의 ZS-CIR 방법들은 학습 중 입력 텍스트의 다양성 부족으로 인해 제한된 backbone 확장성과 일반화 가능성을 보여줍니다. 우리는 새로운 CIR 프레임워크를 제안하며, 이 프레임워크는 오직 언어만을 사용하여 학습합니다. 우리의 LinCIR(CIR을 위한 언어 전용 학습)은 self-masking projection(SMP)이라는 새로운 self-supervision 학습을 통해 텍스트 데이터셋만으로 학습될 수 있습니다. 우리는 텍스트 latent 임베딩을 토큰 임베딩 공간에 투영하고 원본 텍스트의 키워드 토큰을 대체하여 새로운 텍스트를 구성합니다. 그런 다음, 새로운 텍스트와 원본 텍스트가 동일한 잠재 임베딩 벡터를 갖도록 합니다. 이 간단한 전략을 통해 LinCIR은 놀라울 정도로 효율적이고 매우 효과적입니다; CLIP ViT-G 백본을 사용한 LinCIR은 48분 만에 학습되며, CIRCO, GeneCIS, FashionIQ, CIR의 네 가지 다른 CIR 벤치마크에서 최고의 ZS-CIR 성능을 보이며, FashionIQ에서 지도 학습 방법보다 뛰어난 성능을 보였습니다.
